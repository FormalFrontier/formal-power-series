# Changing the defining ideal

Import `FormalPowerSeries.MvPowerSeries.IdealAdicRestricted.IdealChange`.
See the [module](../IdealChange.lean) and its
[client](../../../../FormalPowerSeriesTests/MvPowerSeries/IdealAdicRestricted/IdealChange.lean).

For arbitrary commutative `R`, variable type `σ`, and ideals `I ≤ J`,
`restrictAlongIdeal I J` embeds the `I`-adically restricted subring in the
`J`-adically restricted subring. It changes no coefficient, preserves
polynomial inclusions, and satisfies identity and composition laws.

The surjective ring homomorphism `reductionAtLargerIdeal I J` maps the
`I`-restricted subring to finite polynomials over `R ⧸ J`. Every output
coefficient is the input coefficient modulo `J`; a quotient polynomial
lifts through polynomial inclusion. A series reduces to zero precisely
when all its coefficients belong to `J`. Reduction composes with quotient
factor maps along `J ≤ K` and agrees with restriction to `J` followed by
reduction modulo `K`. This coefficientwise kernel criterion makes no claim
that the kernel is generated by constants inside the restricted subring.

No finiteness, completeness, nontriviality, or valuation assumption is needed.
